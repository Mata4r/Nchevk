# Nchevk
nchevk is a script that was designed for Network Engineers for testing networks.

## Features 

- Reachable Clients with MAC Address if available in the Table

- Clients that are not reachable but exists 

- Gateway check

- Full Summary of the results

## How to run ?

```bash
powershell -ExecutionPolicy Bypass -File .\nchevkscript.ps1
```
### Note

- run the project root folder in power shell.
